🔬 TRAINING PIPELINE
Blender Digital Twin — not a webcam

33 takes · 31,891 frames · Every roll/pitch/yaw from 0° to full inversion · Multiple lighting conditions + clutter · Exact 3D joint ground truth exported automatically — zero manual annotation at any step

Held-out-by-take evaluation (enforced by test)

⚙️ ARCHITECTURE INNOVATIONS
Rack-anchored reference frame (not camera, not floor)

"Box in target zone" and "crew attitude relative to rack" require rack-frame coordinates · Camera-centred frame fails at any roll · Body-centred frame can't express rack-relative position · Our solvePnP+ArUco gives camera→rack transform T ∈ SE(3) · valid even when astronaut is fully inverted

143-dimensional feature vector

hand↔box distance (rack frame) · box-held flag · lid-open state · target-zone occupancy · box velocity · crew attitude angle · MediaPipe wrist positions (roll-corrected, rack-normalised) · updated at 10Hz fixed clock, decoupled from camera FPS

Pose Fusion Gate — 3D with 2D fallback

When HMR3D is confident (joint visibility ≥ threshold) → use 3D wrist positions + crew attitude · When HMR fails or is unsure → fall back to MediaPipe 2D · Same output shape either path · Never blocks · Lose HMR entirely and step recognition still runs at full speed

Adaptive HMR scheduling

HMR3DNet re-runs ONLY when tracked torso angle drifts >15° OR 1 second has passed · Holding still to examine a box costs zero GPU · Fast tumble = checked frequently · EMA-smoothed crop + angle, weight=0.5, prevents jitter

🧠 CLASSIFIER · DECISION · OUTPUT
BiLSTM · 3 layers · 256 hidden units

3-second sliding window = 30 frames at 100ms · Softmax over 9 classes (8 protocol steps + idle) · Updated every 100ms · 73% held-out step accuracy (by-take split, not by frame) · GPU inference: ~2ms · competitors' XGBoost is stateless per-frame

Entropy-gated step confirmation

Confidence threshold alone can't distinguish a decisive prediction from a coin flip that cleared the bar · We additionally gate on Shannon entropy H(p) of the full softmax · Only confirms a step when BOTH confidence ≥ threshold AND entropy is low · Re-derived for our 9-class problem

Protocol State Machine — deterministic ordering

Confirms step on N consecutive frames above threshold (hysteresis, no single-frame flicker) · Flags: skipped step · out-of-order step · repeated step · unexpected idle · Microgravity rules: drift = box moving + no hand near it · placed = box in zone AND released

5 simultaneous outputs — fully offline

🔊 Voice — pyttsx3 offline TTS, step cues + skip alerts · 🖥 Dashboard — PyQt6, live step + 3D overlay · 📄 JSONL log — timestamped, reproducible · 📡 UDP stream — ffmpeg to configurable ground IP · 🎬 Annotated MP4 — skeleton baked in · 0 network calls at runtime

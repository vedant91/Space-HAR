Literature vs. our system
3D pose in microgravityHMR branch
what research shows
Astronaut / microgravity pose estimation is an active, open research problem as recently as 2025–2026.
A1–A4
where it stops
Every system found is a research-stage estimator on its own dataset — none is trained for a specific task rig, suit, or fixed rack camera.
what we built
HMR3DNet, trained on our own Blender digital twin of the exact rack, boxes and suited astronaut. 60° roll: 0.00 → 0.77 tracked joints vs. pretrained HMR.
Sim-to-real domain gapTraining data
what research shows
Synthetic-only training leaves a measurable, closable gap on human body/hand pose (CVPR 2025); Blender-based synthetic pipelines already improve detector accuracy.
B1–B2
where it stops
Demonstrated on generic hands/objects, not on a suited, task-performing human body.
what we built
Measured the same gap ourselves (pretrained HMR: 0.00 at 60° roll) and closed it by rendering denser roll/pitch/lighting angles plus real clips.
Perception backbonesYOLO · MediaPipe
what research shows
YOLOv8 and BlazePose/MediaPipe are mature, general-purpose detectors we build directly on rather than reinvent.
C1–C4
where it stops
Trained on general web/COCO-style data — not our rack, our 3 task boxes, or a pressurised suit.
what we built
YOLOv8n fine-tuned on the task boxes (mAP@50 0.934); MediaPipe kept for the 2D branch; HMR3DNet added only where these networks fail.
Temporal step recognitionBiLSTM + attention
what research shows
Attention-augmented BiLSTM over skeleton sequences is a proven architecture for action recognition.
D1–D3
where it stops
Benchmarked on ground-based, upright, unoccluded subjects — fitness, surveillance, gait.
what we built
Same BiLSTM+attention idea, fed rack-relative, upright-canonicalised features so a floating, suited crew member reads the same at any roll.
Procedural correctness & alertsDecision engine
what research shows
Action segmentation, procedural error detection and entropy-based confidence gating are each studied, separately.
E1–E4
where it stops
No work found combines them into one live system that decides when to actually speak an alert.
what we built
One entropy + confidence gate feeding a deterministic 8-step state machine: confirm → suggest → HOLD → recover.
Real-time, offline deploymentEdge inference
what research shows
Edge HAR is proven real-time on Jetson/Raspberry-Pi-class hardware for a single model.
F1–F2
where it stops
Shown for one lightweight model on simple activities (walk/run) — not a 3-branch vision stack plus a temporal model together.
what we built
Full YOLO + MediaPipe + HMR3DNet + BiLSTM stack running together at 14–16 FPS on one RTX 3050 laptop, zero cloud calls.
Prior art for this exact problem statement: a public repository (AI-Human-Activity-Recognition-for-On-board-BAS-Experiments, GitHub) describes the same skip/out-of-order detection and voice-alert concept for PS 26174. It documents an inference-pipeline simulator with demo datasets; no trained model weights or measured accuracy are reported. G1 — our system trains and measures three real models end to end.
